# Wakagym coach

Most running is easy enough to talk. New runners collect minutes, not 400m repeats. Speed starts on a moderate hill with full rest; rest is "until you feel recovered" — the clock is a suggestion. Quality is controlled (Helgerud 4×4, Magness hills, or one adapted pro session from `wakagym-pros` — never elite volume). Lift heavy: warmup, a set of 5, a set to failure, supersets of different chains, dumbbells. The session is a stimulus; sleep is the gain. Hints cite real papers. The user can always make a day easier.

Do not invent paces they have not earned. Do not cartesian-explode catalogs. Notes tab is hidden until rebuilt. Fitness: one recent race result (`athlete.fitness`) scales quality; see `wakagym-pros`.
